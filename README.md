## Проект 4: фрактальное пламя

### Описание

Реализована программа, которая позволяет генерировать
изображения фрактального пламени на основе идеи Chaos Game.

### Функциональные требования

* Решение предоставляет предоставлять два варианта работы - однопоточный и многопоточный;
* Решение реализовывает цветной алгоритм генерации;
* В решении заложены следующие трансформации:
  * Linear - тождественное преобразование, точка не меняется;
  * Swirl - завихрение вокруг центра с использованием sin/cos от r²;
  * Horseshoe - деформация в форме подковы на основе разности квадратов;
  * Spherical - инверсия относительно единичной окружности (деление на r²);
  * Sinusoidal - применение синуса к каждой координате отдельно;
  * Polar - преобразование в полярные координаты (угол/π и радиус-1);
* В решении представлены следующие параметры генерации и работы:
  * Размер итогового изображения;
  * Количество итераций;
  * Набор трансформационных функций:
    * Вариант функции;
    * Параметры функции;
  * Путь для сохранения изображения;
  * Количество потоков;
* Решение поддерживать несколько вариантов ввода параметров, такие как:
  * Консольный ввод;
  * JSON-файл конфигурации;
  * Параметры по дефолту;
* Решение валидирует входные параметры и сообщать в консоль об ошибках;
* Результатом работы решения является изображение в формате PNG, в цветовом диапазоне RGB, 8 бит на канал;

### Нефункциональные требования

* Время выполнения решения в многопоточном меньше работы в однопоточном;
* Конфигурация решения должна быть простая и интуитивно понятная;
* В случае возникновения ошибки, решение выводит корректное описание исключения и где оно возникло;
* Прогресс работы решения описываться в логах;
* Логи решения содержат прогресс выполнения, сообщения об ошибках и предупреждения;

### Описание входных и выходных данных

В качестве входных данных ожидается увидеть следующие параметры:
* `-w`/`--width` - int, ширина итогового изображения, по дефолту - `1920`;
* `-h`/`--height` - int, высота итогового изображения, по дефолту - `1080`;
*  `--seed` - long, начальное значение генератора, по дефолту - `5`;
* `-i`/`--iteration-count` - int, количество итераций генерации, по дефолту - `2500`;
* `-o`/`--output-path` - строка, относительный путь до файла, в который нужно записать изображение в формате `PNG`, по дефолту - `result.png`;
* `-t`/`--threads` - int, количество потоков, по дефолту - `1`;
* `-ap`/`--affine-params` - конфигурация аффинных преобразований, строка формата `<a_1>,<b_1>,<c_1>,<d_1>,<e_1>,<f_1>/<a_N>,<b_N>,<c_N>,<d_N>,<e_N>,<f_N>`, где:
* `a` - масштаб/вращение X, double, например - `0.1`;
* `b` - сдвиг-смешивание X от Y, double, например - `0.1`;
* `c` - сдвиг по X, double, например - `0.1`;
* `d` - смешивание Y от X, double, например - `0.1`;
* `e` - масштаб/вращение Y, double, например - `0.1`;
* `f` - сдвиг по Y, double, например - `0.1`;
* `\` - разделитель каждого из элементов массива преобразований;
* `-f`/`--functions` - строка, конфигурация применяемых методов трансформации формата `<функция_N>:<вес_функции>,<функция_N>:<вес_функции>`, например - `swirl:1.0,horseshoe:0.8`, где:
* `<функция_N>` - название функции, например, `swirl`;
* `<вес_функции>` - вес применяемой трансформации/функции, double, например - `1.0`;
* `--config` - строка, относительный путь до файла конфигурации (необязательный);

Пример запуска:

```shell
dotnet run --project ./src/Flames/Flames.csproj --width 1200 --height 1200 --iteration-count 5000000 --output-path "galaxy.png" --threads 2 --seed 31415 --symmetry-level 5 --functions "swirl:1.2,linear:0.3" --affine-params "0.8,-0.6,0,0.6,0.8,0/0.6,0.6,0.4,-0.6,0.6,0.4/0.3,0,0,0,0.3,0.7" --gamma-correction true
```

Так же входные параметры можно представить в виде JSON файла `config.json`:

```json

  "width": 3000,
  "height": 3000,
  "iteration_count": 200000000,
  "output_path": "pure_colors.png",
  "threads": 8,
  "seed": 54321,
  "functions": [
    {
      "name": "swirl",
      "weight": 2.5
    },
    {
      "name": "horseshoe",
      "weight": 2.0
    }
  ],
  "affine_params": [
    {
      "a": 1.2, "b": 0.18, "c": 0.0,   "d": -0.18, "e": 1.2, "f": 0.0
    },
    {
      "a": -0.4, "b": 0.72, "c": 0.54,  "d": 0.63, "e": -0.4, "f": 0.0
    },
    {
      "a": 1.1, "b": -0.4, "c": -0.66, "d": 0.4, "e": 1.1, "f": 0.66

```

Пример запуска через CLI с конфигом:

```shell
dotnet run --project src/Flames/Flames.csproj -- --config config.json
```

Приоритет параметров следующий:
* Консольный ввод;
* JSON-файл;
* Параметры по дефолту;

### Бонусные задания

1. +10 бонусных баллов, 5 или больше трансформаций;
2. +10 бонусных баллов, поддержка логарифмической гамма-коррекции
3. +10 бонусных баллов, поддержка симметрии в генерации пламени
4. +10 бонусных баллов, скоро выложу в тг результат и надеюсь получу лайк)
